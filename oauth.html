Подключение Pinterest API к MoneyMint autopost

Эта страница ничего никуда не отправляет. Секрет приложения здесь не вводится — только в Терминале на твоём Mac.

Шаг 1. Вставь App ID своего приложения (developers.pinterest.com → My apps):
Шаг 2. Pinterest вернул код. Открой Терминал на Mac, вставь команду ниже, замени ВСТАВЬ_APP_SECRET на секрет приложения и нажми Enter: 


В ответе найди "refresh_token": "..." — скопируй значение (без кавычек) и сохрани его в GitHub: репозиторий moneymint-pins → Settings → Secrets and variables → Actions → New repository secret → имя PINTEREST_REFRESH_TOKEN.


Код действует несколько минут. Если команда вернула ошибку — начни с шага 1 заново.
